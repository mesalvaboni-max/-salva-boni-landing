# Salva Boni - Landing Page

Landing page profissional para **Salva Boni** - Planejamento Financeiro Estratégico para Médicos.

## 📋 Sobre

Salva Boni é um método exclusivo de planejamento patrimonial desenvolvido para médicos em início de carreira. Esta landing page apresenta o método, os planos disponíveis e facilita a conversão de visitantes em clientes.

## 🎯 Características

- ✅ **Design Premium** - Azul escuro, dourado e minimalista
- ✅ **Mobile First** - Responsivo e otimizado para todos os dispositivos
- ✅ **Transições Suaves** - Animações fluidas entre seções
- ✅ **Ticker Animado** - Mensagem dinâmica na transição hero
- ✅ **FAQ Interativa** - Perguntas e respostas em acordeão
- ✅ **Planos Destacados** - Essencial e Premium bem diferenciados
- ✅ **Depoimentos** - Médicos reais compartilhando experiências
- ✅ **Otimizado** - Carregamento rápido, sem dependências externas

## 📁 Estrutura

```
salva-boni-landing/
├── index.html          # Página principal (landing page completa)
├── vitor.png          # Foto do Vitor Bonilha
└── README.md          # Este arquivo
```

## 🚀 Como Usar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/salva-boni-landing.git
   cd salva-boni-landing
   ```

2. **Abra a landing page:**
   - Abra o arquivo `index.html` no navegador
   - Ou hospede em um servidor web

3. **Para editar:**
   - Edite o arquivo `index.html` com seu editor de código favorito
   - Mantenha a imagem `vitor.png` na mesma pasta
